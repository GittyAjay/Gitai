# GitLogger CLI

A powerful Git log analysis and reporting tool with AI-powered insights.

## Quick Installation

With sudo access:

```bash
curl -o- https://raw.githubusercontent.com/GittyAjay/Gitai/dev/gitlogger-cli.sh | sudo bash -s -- install
```

Without sudo access:

```bash
curl -o- https://raw.githubusercontent.com/GittyAjay/Gitai/dev/gitlogger-cli.sh | bash -s -- install
```

After installation, restart your terminal or run:

```bash
source ~/.bashrc
```

## Usage

Run `gitlogger help` to see available commands.

## Requirements

- Git
- Bash
- curl (for installation)
